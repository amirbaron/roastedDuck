# Engineering reports

Current user documentation is at **https://amirbaron.github.io/roastedDuck/**.
Its source is in `website/docs/`.

This directory retains the port's dated engineering history. Older reports
contain open items and local artifact paths from the time they were written;
they are not a live support matrix.

The latest historical qualification is
[November 6 candidate](release-candidate-index-20261106.md), with
[known exceptions](release-known-exceptions.md) and
[native performance](performance-final-native-20261106.md). Public packaging
preserves the candidate engine and has separate installation checks. Curated
downloadable measurements live in `website/docs/evidence/`.
